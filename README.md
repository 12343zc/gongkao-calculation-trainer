# 算有章 · 公考资料分析计算训练器

轻量、无依赖、无后端的静态网页应用，按 PRD v1.0 的 P0 范围实现。训练数据保存在当前浏览器，不上传。

## 启动

安装 Node.js 20 或更新版本，在本文件所在目录运行：

```sh
node scripts/serve.mjs
```

浏览器打开 `http://localhost:4173`。也可使用 `npm start`，不需要安装依赖。不要直接双击 index.html：浏览器通常禁止 file:// 页面加载 JavaScript 模块。

手机、iPad 和电脑在同一局域网时，可在手机浏览器访问 `http://电脑的局域网IP:4173`；电脑防火墙须允许本地服务。正式使用建议部署 GitHub Pages，以便直接通过 HTTPS 打开。

## 测试

```sh
node --test tests/math.test.js tests/generator.test.js tests/storage-stats.test.js
```

或 `npm test`。无第三方测试依赖。测试覆盖每个专项的批量生成、数字位数、实际进位/借位/跨零过程、精确除法、两三位有效数字与进位边界、数量级区间、单位量纲、误差阈值、错题状态和存储/统计。

## GitHub Pages 部署

将本目录的**内容**作为仓库根目录上传，确保根目录能看到 `index.html`、`src/`、`package.json` 和 `.github/workflows/pages.yml`，而不是在外面再套一层文件夹。

1. 新建 GitHub 仓库，免费账户可使用公开仓库来发布 Pages。默认分支为 `main`。
2. 上传完整源码（包括 `.github` 隐藏文件夹）。
3. 在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
4. 打开 **Actions → Deploy GitHub Pages → Run workflow** 手动运行；之后每次推送到 main 会自动测试并部署。
5. 等待工作流中 `test`、`deploy` 成功。发布地址由工作流提供，通常为 `https://你的用户名.github.io/仓库名/`。

所有网页资源路径均为相对路径，兼容 GitHub Pages 仓库子目录。没有 API 密钥、环境变量、数据库或构建步骤。

也可以不使用 Actions：选择 Pages 的 **Deploy from a branch → main → /(root)**。此方式直接发布静态文件，但不会在发布前自动运行测试。

## 5 分钟使用方法

1. 选择专项，例如 **基础加减 → 跨零借位**。
2. 选择 10 题，按需要打开整组限时，默认限时 5 分钟。
3. 使用实体键盘或屏幕数字键盘答题，Enter 或按钮提交；带单位题还需选择单位。
4. 查看正确答案、必要说明及估算误差，手动进入下一题。可以先跳过，系统会将原题移至本组后面。
5. 训练报告显示正确率、整组用时、平均用时、各题型表现和逐题记录。错题可标记原因，并从报告或错题本原样重做。

## 已实现

- 基础加减：两位数不进位/个位进位、连续求和、不退位/个位退位、跨整十；三位数连续进位、连续借位、跨零借位、凑整补偿、3–5 项连续加减。
- 乘法：2×1、2×2、3×1、3×2 位数、进位专项、近整十整百、乘积位数；精算/估算。
- 除法：3÷1、3÷2、3÷3、4÷2、4÷3 位数、带小数、同时缩放；有限小数精确计算、数量级估商、商的两/三位有效数字。
- 数量级：整数、小数乘除，互不重叠的左闭右开区间。
- 单位：元/万/亿、人/万/亿、吨/万/亿、千米/万千米、百分数/小数/倍数、三类基础带单位除法；同时校验数值和单位。
- 截位：两/三位有效数字，四舍五入/直接截断；保持数量级，展示原数、近似数、近似算式、精确结果、绝对误差和相对误差。
- 专项/六模块混合/错题原题重练，10/20/1–100 自定义题量，整组 1–60 分钟可选限时。
- 单题用时、跳题稍后回看、提前结束/自动到时交卷、训练报告、各题型统计、历史逐题回看。
- 12 类手动错因标记，明显倍数偏差提示，默认待确认；未作答题也保留用于重练。
- 本地设置、历史、答案、用时和错题状态持久化，清空前二次确认。
- 手机/iPad/桌面响应布局、实体键盘和屏幕数字键盘。

## 判定及统计口径

- 精确题：使用 BigInt 分数比较。`0.3` 和 `0.300` 等价，精确题没有额外模糊容差。
- 有效数字题：数值需等于按指定规则处理的结果，不要求强制补写末尾零。
- 估算题及数量级数值估值：可自选 0%–20% 允许相对误差（步长 1%，默认 5%）。0% 生成有限小数并严格精确判定；小误差要求下，参考截位计算可能仍需进一步精算。数量级的原十倍区间保留为独立基础专项。
- 相对误差：`|用户值−精确值| / |精确值|`；精确值为零时改用绝对误差阈值（默认 0.01）。当前估算题生成池不生成零结果，但校验器覆盖此规则。
- 循环小数展示约值（最多 10 位小数），同时显示精确分数，判定仍使用分数。
- 总题数：本组全部题。正确率含未作答题；整组平均用时为组总用时/总题数，包含查看反馈的时间。
- 各题型平均答题用时只累计该题开始到提交的时间，含跳题前的时间，不含提交后读反馈的时间。
- 整组限时包括查看反馈与页面后台停留，切回页面会立即检查到时状态。
- 错因仅由用户确认。即使出现 10、100、10000 倍差异，也只提示可能问题，不断言心算过程。
- 纠正错题后原始历史保持不变；原题标为已纠正。再次答错会重新进入待巩固。
- 下一次训练建议仅基于当前报告中最低正确率题型，并不包含 P1 的自适应出题功能。

## 已知限制

- 当前组进度在内存中，刷新或关闭会提示离开，强制离开会丢失尚未完成的本组；已结束的训练不受影响。
- 数据隔离于设备、浏览器和网页来源。无痕窗口、清理浏览器或切换网址可能导致记录不可见或被清除。
- 未设置历史容量上限。达到浏览器配额时会提示无法保存；初版没有数据导出备份。
- 基础/进阶目前主要调整乘除法混合池；明确选择专项时以该专项位数条件为准。
- 需要支持 BigInt、ES 模块和 structuredClone 的现代浏览器（建议 iOS/iPadOS 16+ 及现代 Chrome/Edge/Safari）。
- 单位混合只覆盖三类固定量纲模板，未包含完整资料分析公式库。
